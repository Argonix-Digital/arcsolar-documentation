If you can't find a page that a colleague can see, it is almost always one of three things: your **role**, your company's **plan**, or a feature that is **not released yet**.

## What each role can open

Your role is shown under your name at the bottom of the sidebar. An administrator sets it. See [Roles and permissions](/setup/roles).

| Page | Administrator | Operations | Sales manager | Sales representative | Finance | External marketing |
| --- | :-: | :-: | :-: | :-: | :-: | :-: |
| **Inbox**, **Rep Overview** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **Tasks** | ✓ | ✓ | ✓ | ✓ | ✓ | |
| **Sales**, **Quotes**, **Customers**, **Comms** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **Roof Vision** | ✓ | ✓ | ✓ | ✓ | | |
| **Projects & Jobs**, **Calendar**, **Product Catalogue** | ✓ | ✓ | ✓ | ✓ | ✓ | |

| **Settings** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **Team & Access** | ✓ | ✓ | | | ✓ | |

A few more rules:

- **Technicians** don't use the main app. They sign in to their own job list. See [Job portal and technician access](/delivery/job-portal).
- **Sales representatives** see their own customers and unassigned ones. **Sales managers** see the customers of the reps they manage. Most other roles see every customer.
- **Finance** mostly views sales and project work, and records and reconciles payments.
- **External marketing** can add leads and see lead results, but can't create quotes or change projects.
- Being able to open a page doesn't mean you can do everything on it. For example, some settings need an administrator.

## Badges in the app

| Badge or label | What it means |
| --- | --- |
| **New** | Recently added |
| **Beta** | Works, but is still being improved. Check the result. |
| **Soon** / **Coming soon** | Not available yet. It is greyed out and can't be opened. |
| **Mock data** | You are in the demo. All records are fictional. |
| **Disconnected** | A connected service needs setting up again before it updates |
| **Processing** / **Pending** | Waiting for confirmation. Check back before acting. |

## Features that depend on your plan

ArcSolar has two plans: **Spark** and **Arc**. **Arc** adds **Roof Vision** and ArcSolar's AI features. An administrator can see your plan in Settings → **Billing** → **Manage subscription**.

If **Roof Vision** says **Roof Vision is not enabled**, your company is on Spark. Some long-standing companies have Roof Vision by arrangement. Support can confirm.

## Features that depend on your company's setup

- **Agent** (marked **Beta**) appears in the sidebar only when it is switched on for your company. See [Agent](/agent).
- **Amy**, the AI appointment setter, appears only when your company uses it.
- **Selling intelligence** shows as **Soon** and can't be opened yet.

## Additional selling brands

Every company has one **original selling brand**. You can add more, each with its own price book, contract, logo and fonts.

**An additional brand can save quote drafts, but it cannot send a quote yet.** No role or setting changes this. If you try, you see **This selling brand is not ready to issue**. See [Selling brands FAQ](/reference/selling-brands-faq).

## Apps

There is no ArcSolar phone or desktop app yet. Use ArcSolar in your web browser on any device. See [Find your way around](/reference/workspace#mobile-and-desktop-apps).

## The demo

[demo.arcsolar.com.au](https://demo.arcsolar.com.au) shows ArcSolar with fictional records and a **Mock data** badge. Screenshots in these docs come from it. Some demo-only menus, such as **Demo previews** and **Misc**, don't appear in your workspace, and changes you make there aren't saved to a real account.
