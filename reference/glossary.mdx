| Term | Meaning |
| --- | --- |
| Workspace / organisation | Your business's ArcSolar environment |
| Lead | A new enquiry |
| Opportunity | A potential sale being worked |
| Quote / estimate | An issued offer with its saved terms |
| Snapshot | The saved version used by an issued document |
| BOM | Bill of materials: equipment and quantities |
| Roof Design / Roof Vision | The roof editor opened from a quote. It draws the panel layout and the stringing and component layout. ArcSolar opens it and stores the result; the editor produces the design. |
| Panel layout | The design image showing where the panels sit on the roof. |
| Stringing | How panels are grouped into strings and the order they connect in. The only thing ArcSolar holds is the **Stringing and component layout** image, not the underlying electrical values. |
| Single line diagram (SLD) | The electrical schematic of the system. It is produced by the external Roof Design editor, and its state is stored inside the design document ArcSolar keeps. ArcSolar does not draw, calculate or display an SLD. |
| Proposed rooftop design | The older provider-based roof analysis shown in an estimate, with capacity and exposure figures. It is not the same as **Roof design**. |
| Google Solar | The provider analysis behind the older rooftop design path. It needs the roof vision entitlement, and the saved analysis must be no more than 30 days old. |
| STC | Small-scale technology certificate used in the applicable incentive calculation |
| CER zone | Location-based input used in the relevant solar STC calculation |
| Accreditation code | Installation identifier used for supported REC Registry checks |
| Rebate | A benefit subject to the program's rules |
| Government loan | Repayable funding, not a discount |
| Deposit | Upfront amount in the customer's payment schedule |
| PayTo mandate | Bank-authorised permission to collect payments under agreed terms |
| Stripe Connect | The connection used to enable customer-payment collection |
| Settlement | Confirmation of the relevant money movement |
| Grid imports | Electricity bought from the grid |
| Feed-in tariff | Rate credited for electricity exported |
| kW | Power or system capacity |
| kWh | Energy used, produced or stored |
| NMI | National Metering Identifier for an electricity connection |
| VoIP | Phone calls carried over an internet connection |
| SMS segment | A billable part of an SMS message |
| CallIntelligence | Supported call summary/transcript context |
| Sync | Update information from a connected provider |
| Readiness | Requirements that must be met before a job proceeds |
